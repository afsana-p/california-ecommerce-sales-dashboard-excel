# california-ecommerce-sales-dashboard-excel
Interactive Excel dashboard analysing 2,400 California e-commerce orders (Q1 2025) with Pivot Tables, slicers, map and trend charts: revenue, products, order channels, counties, customer ratings and delivery time.

## 📂 Dataset
2,400 orders | 20 products | 5 order channels | California counties  
Key columns: Product, Quantity, Unit Price, Amount, Order Date, Ship Date, Gender, Order Mode, Rating, County  
Calculated columns: Days to Deliver, Weeknum, Gender Value

## 🛠️ Tools
Excel • Pivot Tables • Pivot Charts • Slicers (Order Mode, Gender) • Map Chart • KPI Cards

## 📊 Key Insights
- **Revenue:** ~$649K from 11,997 units (avg. order value ≈ $270)
- **Top products:** Sneakers (~$128K) and Jeans (~$113K) by revenue
- **Customers:** Women buy ~52% of units; most orders contain 2 items
- **Channels:** App leads with ~35% of revenue, then Website (~24%) and Target.com (~18%)
- **Location:** Los Angeles (~33%) and San Diego (~15%) make up ~48% of sales
- **Delivery:** average 2.3 days; ~67% of orders ship within 2 days
- **Ratings:** average 3.96/5; ~73% of orders rated 4–5 stars
- **Trend:** sales peaked in week 10 ($64.9K)

## 💡 Recommendations
- Invest more in the App channel and top-selling products
- Expand marketing beyond LA and San Diego
- Offer "buy 2" bundles and review low-rated orders to improve satisfaction
